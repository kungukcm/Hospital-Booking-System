# REFERENCE VERIFICATION AND FOOTNOTE GUIDE

## Purpose

This companion file helps transform the current reference drafts into a final APA 7 bibliography and supports citation consistency during final thesis formatting.

## 1. Why Verification Matters

The reference folder contains PDFs and DOCX files with mixed metadata visibility. Some files expose full citation details, while others require manual inspection. A draft bibliography is useful, but final submission requires exact metadata.

## 2. Recommended Verification Workflow

1. Open each source file.
2. Extract author names, year, title, source type, pages, DOI, or URL.
3. Compare metadata against the draft matrix.
4. Correct duplicates and versioned copies.
5. Alphabetize by first author surname.
6. Apply APA 7 punctuation and capitalization rules.

## 3. Citation Placement Rules for the Thesis Draft

1. Use chapter-level citations where claims are synthesized from multiple sources.
2. Reserve specific source citations for definitive claims or direct conceptual support.
3. Avoid over-citing the same source in adjacent sentences where synthesis can be grouped.
4. Match every in-text citation to a final bibliography entry.

## 4. Handling Duplicate or Versioned Files

The folder includes some duplicate or versioned sources. For final submission:

1. identify which file is the primary or most complete version;
2. use only one reference entry for that work unless the versions are genuinely distinct;
3. document duplicates in a personal verification note, not in the thesis bibliography.

## 5. Suggested Bibliography Structure

### Core Sections

1. Journal articles
2. Conference papers
3. Reports and white papers
4. Working papers or preprints
5. Supplementary or contextual sources

### Sorting Principle

Alphabetize by first author surname after final metadata normalization.

## 6. Footnote and Note Usage

If your departmental style allows notes, use them only for very short clarification, not for substantive argumentation. Keep the thesis body clean and aligned with standard academic prose.

## 7. Common APA 7 Issues to Check

1. Title capitalization
2. Journal title italics
3. Volume and issue formatting
4. Page range inclusion
5. DOI vs URL handling
6. Conference proceedings formatting
7. Organization author formatting
8. Missing publication years

## 8. Source Mapping Note

Where metadata remains uncertain, the thesis should not invent details. Use the draft matrix as a placeholder and fill it only after confirming the source text.

## 9. Practical Advice for Final Assembly

1. Convert the manuscript into Word.
2. Replace placeholder references with exact APA entries.
3. Insert hanging indents.
4. Update cross-references and citations after final bibliography insertion.
5. Review the thesis in PDF form before submission.

## 10. Final Reminder

This guide is meant to prevent citation errors, especially with versioned or partially legible reference files. Accurate referencing is part of thesis quality and academic integrity.
